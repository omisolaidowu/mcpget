# Security Policy

## Reporting a vulnerability

Please do not report exploitable vulnerabilities in public issues. Contact the repository maintainers privately through the security reporting channel configured for this repository. No private channel has been configured in this initial repository; until one is available, avoid sharing sensitive exploit details publicly and contact a maintainer directly.

## Scope

MCPGet is at its repository foundation milestone and does not yet discover or install MCP servers. Future security-sensitive features will be reviewed against [the security model](docs/development/SECURITY_MODEL.md). Never submit credentials, tokens, or private configuration in bug reports.
